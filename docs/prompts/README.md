# Codex prompts

These prompts are designed to be copied into Codex with minimal editing. Replace placeholders such as `YOUR_ORG`, paths, and branch names.

Recommended usage:

1. Start each milestone with the corresponding `P*_plan.md` prompt in plan mode.
2. After approving the plan, use the `P*_implement.md` prompt or ask Codex to implement the approved plan.
3. End each session with `R_update_docs_worklog.md` and then `R_review_diff.md`.
