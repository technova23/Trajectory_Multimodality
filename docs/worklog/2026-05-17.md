# Work log — 2026-05-17

## Objective

Migrate the active simulator stack from RLBench/PyRep/CoppeliaSim to ManiSkill/SAPIEN without
preserving RLBench as an alternate backend.

## Summary

- Removed active RLBench adapter code, smoke scripts, tests, setup runbook, and generated artifacts.
- Added a lightweight ManiSkill adapter namespace with simulator-neutral observation dataclasses.
- Added a non-rendering ManiSkill `PickCube-v1` smoke script and Makefile target.
- Rewrote current prompts, runbooks, status docs, architecture docs, and simulator ADRs around
  the ManiSkill reach-first path.
- Kept RLBench mentions only as historical migration context in prior worklogs, the superseded
  ADR, the migration ADR, and the status deprecation note.
