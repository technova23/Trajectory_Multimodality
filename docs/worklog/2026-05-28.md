# 2026-05-28

## DP3 multimodality probe

- Added `pg3d.multimodality`, a dataset-only checkpoint probe that repeatedly samples one fixed
  DP3 observation window and writes stochastic action chunks to `samples.npz`, diversity diagnostics
  to `summary.json`, and an overlay/PCA plot to `action_chunks.png`.
- Added a Plotly.js `action_trajectories.html` export, adapted from the local visualizer pattern,
  for a rotatable 3D PCA view of sampled action trajectories without requiring Python Plotly.
- Added `--keep-diverse` farthest-first selection so the probe can sample a larger candidate pool
  and save the most spread-out subset as `selected_*` artifacts.
- Added `--mode success-rollouts`, a simulator-backed same-start/target filter that reruns
  stochastic closed-loop rollouts and copies only ManiSkill-successful attempt videos to
  `success_videos/`.
- Documented the command in `docs/runbooks/commands.md`.
- Added pure tests for pairwise RMS diversity stats and dataset episode-to-sequence selection.
