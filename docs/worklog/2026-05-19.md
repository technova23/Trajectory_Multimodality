- Added ordered goal-token conditioning for DP3 reach without adding a new policy-visible key:
  `obs.point_cloud` keeps shape `[N, 3]`, and the final K point slots are overwritten from
  `/data/target_position` at dataset-load and live policy-input time.

  `goal_marker_radius=0.015`; `K=0` remains available for old checkpoint compatibility and
  ablations.

  existing PointNet scene branch over the first `N-K` points.

  target regions for the next base reach checkpoint.
- Added `scripts/diagnose_reach_dataset.py` for target-distribution, raw goal-visibility,
  marker-correctness, and train/validation region-balance checks.
- Updated training/eval/rollout/constrained-eval paths so checkpointed marker settings are applied
  consistently in policy input tensors.
- Deferred Franka gripper / custom URDF / Robotiq work to a later manipulation milestone; it is not
  on the critical path for base reach reliability.
